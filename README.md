<details>
<summary><b>🚀 1. لوحة تحكم تحليل المخاطر (Security Dashboard)</b></summary>
<p align="center"><img src="assets/all_assets/page_042_img_00.jpeg" width="350"></p>

### 📋 Technical Breakdown:
تعتبر هذه الواجهة هي "العقل المفكر" للمستخدم. يقوم محرك `SecurityScoreEngine` بحساب درجة الأمان بناءً على تقاطع أذونات التطبيقات مع مصادرها. 
*   **الخوارزمية**: يتم وزن كل تطبيق بـ (Risk Points). إذا تجاوز التطبيق 40 نقطة، يتحول اللون إلى الأحمر القاني (Danger).
*   **تجربة المستخدم**: استخدام الـ Glassmorphism يعطي شعوراً بالحداثة والأمان الفائق.
</details>

<details>
<summary><b>🛡️ 2. الفحص العميق بمحرك YARA (Deep System Scan)</b></summary>
<p align="center"><img src="assets/all_assets/page_166_img_00.jpeg" width="350"></p>

### 📋 Technical Breakdown:
هنا تظهر قوة لغة **C++ Native**. هذه الشاشة تدير عملية المسح الشامل للملفات.
*   **Binary Analysis**: لا يكتفي النظام بأسماء الملفات، بل يحلل "البصمة الثنائية" للملف مقابل قواعد YARA العالمية.
*   **الأداء**: بفضل مكتبة JNI، تتم عملية الفحص في مسار (Thread) منفصل تماماً عن الواجهة لضمان عدم حدوث Lag.

### 🔬 لماذا GuardianX يتفوق على العمالقة (Kaspersky, Avast)؟
1.  **AI Privacy**: نستخدم **Local ONNX Inference**؛ بينما يرسل الآخرون روابطك إلى خوادمهم، نحن نفحصها في هاتفك.
2.  **Native Power**: استخدام C++ JNI يمنحنا وصولاً أعمق لطبقات النظام (Kernel-level indicators) لا تصل إليها التطبيقات المكتوبة بالجافا فقط.
3.  **7-Layer URL Security**: نظامنا لا يعتمد على قائمة سوداء فقط، بل يحلل الـ HTML ويبحث عن نماذج التصيد الاحتيالي حياً.
